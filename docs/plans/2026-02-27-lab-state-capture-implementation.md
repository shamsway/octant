# Lab State Capture Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Capture a point-in-time snapshot of all installed software versions and deployed container images, producing JSON and markdown output.

**Architecture:** An Ansible playbook gathers three layers of data: per-host facts (packages, services, OS), cluster-level state (Consul/Nomad/Ceph APIs), and intended image state (parsed from Terraform variables.tf files). All data is assembled into a JSON file. A Python script converts the JSON into a formatted markdown report. The playbook runs on-demand via `make capture-state` and automatically after `make deploy-services`.

**Tech Stack:** Ansible (package_facts, service_facts, uri module), Nomad HTTP API, Consul HTTP API, Ceph CLI, Python 3, Makefile

**Reference:** [Design doc](2026-02-27-lab-state-capture-design.md)

### Task 1: Create the state capture playbook

The playbook has two plays: one targeting the cluster servers (to gather host facts and cluster APIs), and one targeting localhost (to scan Terraform vars and assemble the final JSON).

**Files:**
- Create: `playbooks/07-capture-state.yml`

**Step 1: Create the playbook file**

```yaml
---
# Octant Lab State Capture
# Captures installed software versions, service states, and deployed job images
#
# Usage:
#   ansible-playbook playbooks/07-capture-state.yml -i inventory/provisioned_vms.yml -i inventory/groups.yml
#
# Output:
#   docs/state/lab-state.json  - Machine-readable state
#   docs/state/lab-state.md    - Human-readable report (generated by scripts/state-to-markdown.py)

# Play 1: Gather per-host facts and cluster-level state from servers
- name: Gather cluster state
  hosts: servers
  gather_facts: true
  become: true

  vars:
    tracked_packages:
      - consul
      - nomad
      - podman
      - ceph-common
      - nomad-driver-podman
    tracked_services:
      - consul-server
      - consul-agent
      - consul-agent-root
      - nomad-server
      - nomad-agent
      - nomad-agent-root
      - node-exporter
    cluster_host: "{{ groups['servers'][0] }}"
    nomad_addr: "http://localhost:4646"
    consul_addr: "http://localhost:8500"

  tasks:
    # --- Per-host facts ---
    - name: Gather package facts
      ansible.builtin.package_facts:
        manager: auto

    - name: Gather service facts
      ansible.builtin.service_facts:

    - name: Build per-host package versions
      ansible.builtin.set_fact:
        host_packages: >-
          {{
            host_packages | default({}) | combine({
              item: (ansible_facts.packages[item][0].version
                     if item in ansible_facts.packages else 'not installed')
            })
          }}
      loop: "{{ tracked_packages }}"

    - name: Build per-host service states
      ansible.builtin.set_fact:
        host_services: >-
          {{
            host_services | default({}) | combine({
              item: (ansible_facts.services[item + '.service']['state']
                     if (item + '.service') in ansible_facts.services else 'absent')
            })
          }}
      loop: "{{ tracked_services }}"

    - name: Assemble host info
      ansible.builtin.set_fact:
        host_info:
          os: "{{ ansible_facts['distribution'] }} {{ ansible_facts['distribution_version'] }} ({{ ansible_facts['distribution_release'] }})"
          kernel: "{{ ansible_facts['kernel'] }}"
          ram_mb: "{{ ansible_facts['memtotal_mb'] }}"
          vcpus: "{{ ansible_facts['processor_vcpus'] }}"
          uptime_seconds: "{{ ansible_facts['uptime_seconds'] }}"
          ip: "{{ ansible_facts['default_ipv4']['address'] }}"
          packages: "{{ host_packages }}"
          services: "{{ host_services }}"

    # --- Cluster-level state (run once on first server) ---
    - name: Get Consul agent self info
      ansible.builtin.uri:
        url: "{{ consul_addr }}/v1/agent/self"
        return_content: true
      register: consul_self
      when: inventory_hostname == cluster_host

    - name: Get Consul members
      ansible.builtin.uri:
        url: "{{ consul_addr }}/v1/agent/members"
        return_content: true
      register: consul_members_raw
      when: inventory_hostname == cluster_host

    - name: Get Nomad agent self info
      ansible.builtin.uri:
        url: "{{ nomad_addr }}/v1/agent/self"
        return_content: true
      register: nomad_self
      when: inventory_hostname == cluster_host

    - name: Get Nomad server members
      ansible.builtin.uri:
        url: "{{ nomad_addr }}/v1/agent/members"
        return_content: true
      register: nomad_members_raw
      when: inventory_hostname == cluster_host

    - name: Get Ceph status
      ansible.builtin.command: ceph status --format json
      register: ceph_status_raw
      changed_when: false
      when: inventory_hostname == cluster_host

    - name: Get Ceph version
      ansible.builtin.command: ceph -v
      register: ceph_version_raw
      changed_when: false
      when: inventory_hostname == cluster_host

    - name: Get Nomad jobs list
      ansible.builtin.uri:
        url: "{{ nomad_addr }}/v1/jobs"
        return_content: true
      register: nomad_jobs_raw
      when: inventory_hostname == cluster_host

    - name: Get allocations for each job
      ansible.builtin.uri:
        url: "{{ nomad_addr }}/v1/job/{{ item.ID }}/allocations"
        return_content: true
      register: nomad_allocs_raw
      loop: "{{ nomad_jobs_raw.json }}"
      loop_control:
        label: "{{ item.ID }}"
      when: inventory_hostname == cluster_host

    - name: Build job image map from live allocations
      ansible.builtin.set_fact:
        live_jobs: >-
          {{
            live_jobs | default({}) | combine({
              item.item.ID: {
                'status': item.item.Status,
                'type': item.item.Type,
                'node': ((item.json | selectattr('ClientStatus', 'equalto', 'running') | list | first).NodeName
                         if (item.json | selectattr('ClientStatus', 'equalto', 'running') | list | length > 0)
                         else 'none'),
                'image_live': ((item.json | selectattr('ClientStatus', 'equalto', 'running') | list | first).TaskGroup
                               if (item.json | selectattr('ClientStatus', 'equalto', 'running') | list | length > 0)
                               else 'unknown')
              }
            })
          }}
      loop: "{{ nomad_allocs_raw.results }}"
      loop_control:
        label: "{{ item.item.ID }}"
      when: inventory_hostname == cluster_host

    - name: Build cluster facts
      ansible.builtin.set_fact:
        cluster_facts:
          consul:
            version: "{{ consul_self.json['Config']['Version'] }}"
            datacenter: "{{ consul_self.json['Config']['Datacenter'] }}"
            members: "{{ consul_members_raw.json | map(attribute='Name') | list }}"
            leader: "{{ consul_self.json['Stats']['consul']['leader_addr'] | default('unknown') }}"
          nomad:
            version: "{{ nomad_self.json['config']['Version']['Version'] }}"
            region: "{{ nomad_self.json['config']['Region'] }}"
            members: "{{ nomad_members_raw.json['Members'] | map(attribute='Name') | list }}"
            leader: "{{ nomad_self.json['stats']['nomad']['leader'] | default('unknown') }}"
          ceph:
            version: "{{ ceph_version_raw.stdout.split()[2] }}"
            codename: "{{ ceph_version_raw.stdout.split()[4] | default('unknown') }}"
            health: "{{ (ceph_status_raw.stdout | from_json)['health']['status'] }}"
            osds: "{{ (ceph_status_raw.stdout | from_json)['osdmap']['num_osds'] | default((ceph_status_raw.stdout | from_json).get('osd_count', 'unknown')) }}"
      when: inventory_hostname == cluster_host

# Play 2: Scan Terraform vars, assemble JSON, generate markdown (runs on controller)
- name: Assemble state and generate output
  hosts: localhost
  connection: local
  gather_facts: false

  vars:
    state_dir: "{{ playbook_dir }}/../docs/state"
    terraform_dir: "{{ playbook_dir }}/../terraform"
    scripts_dir: "{{ playbook_dir }}/../scripts"
    cluster_host: "{{ groups['servers'][0] }}"

  tasks:
    - name: Ensure state output directory exists
      ansible.builtin.file:
        path: "{{ state_dir }}"
        state: directory
        mode: "0755"

    - name: Find all terraform variables.tf files
      ansible.builtin.find:
        paths: "{{ terraform_dir }}"
        patterns: "variables.tf"
        recurse: true
        depth: 2
      register: tf_var_files

    - name: Read terraform variables.tf files
      ansible.builtin.slurp:
        src: "{{ item.path }}"
      register: tf_var_contents
      loop: "{{ tf_var_files.files }}"
      loop_control:
        label: "{{ item.path | basename | dirname }}"

    - name: Parse intended images from terraform variables
      ansible.builtin.set_fact:
        intended_images: >-
          {{
            intended_images | default({}) | combine({
              (item.source | regex_replace('.*/terraform/([^/]+)/.*', '\1')):
              (item.content | b64decode | regex_search('variable\s+"image"\s+\{[^}]*default\s*=\s*"([^"]+)"', '\1') | first | default('not defined'))
            })
          }}
      loop: "{{ tf_var_contents.results }}"
      loop_control:
        label: "{{ item.source | regex_replace('.*/terraform/([^/]+)/.*', '\\1') }}"
      when: "(item.content | b64decode) is search('variable\\s+\"image\"')"

    - name: Assemble complete state JSON
      ansible.builtin.set_fact:
        lab_state:
          captured_at: "{{ ansible_date_time.iso8601 | default(lookup('pipe', 'date -u +%Y-%m-%dT%H:%M:%SZ')) }}"
          cluster: "{{ hostvars[cluster_host]['cluster_facts'] }}"
          hosts: >-
            {{
              dict(groups['servers'] | zip(
                groups['servers'] | map('extract', hostvars, 'host_info') | list
              ))
            }}
          jobs: >-
            {{
              hostvars[cluster_host]['live_jobs'] | default({}) | combine(
                dict(intended_images | default({}) | dict2items | map(attribute='key') | zip(
                  intended_images | default({}) | dict2items | map(attribute='key') | map('extract',
                    hostvars[cluster_host]['live_jobs'] | default({})) | list
                ) | rejectattr('1', 'none') | list),
                recursive=true
              )
            }}
          intended_images: "{{ intended_images | default({}) }}"

    - name: Write state JSON
      ansible.builtin.copy:
        content: "{{ lab_state | to_nice_json }}"
        dest: "{{ state_dir }}/lab-state.json"
        mode: "0644"

    - name: Generate markdown report
      ansible.builtin.command:
        cmd: "python3 {{ scripts_dir }}/state-to-markdown.py {{ state_dir }}/lab-state.json {{ state_dir }}/lab-state.md"
      changed_when: true

    - name: Display state capture summary
      ansible.builtin.debug:
        msg: |
          === STATE CAPTURE COMPLETE ===
          JSON: {{ state_dir }}/lab-state.json
          Markdown: {{ state_dir }}/lab-state.md
          Hosts: {{ groups['servers'] | length }}
          Jobs: {{ (hostvars[cluster_host]['live_jobs'] | default({})) | length }}
          ==============================
```

### Task 2: Create the Python markdown generator

This script reads the JSON state file and produces a clean markdown report with tables.

**Files:**
- Create: `scripts/state-to-markdown.py`

**Step 1: Create the script**

```python
#!/usr/bin/env python3
"""Convert lab-state.json to a formatted markdown report."""

import json
import sys
from datetime import datetime
from pathlib import Path


def main():
    if len(sys.argv) != 3:
        print(f"Usage: {sys.argv[0]} <input.json> <output.md>", file=sys.stderr)
        sys.exit(1)

    input_path = Path(sys.argv[1])
    output_path = Path(sys.argv[2])

    with open(input_path) as f:
        state = json.load(f)

    lines = []
    lines.append("# Octant Lab State")
    lines.append("")
    lines.append(f"**Captured:** {state['captured_at']}")
    lines.append("")

    # Cluster overview
    lines.append("## Cluster")
    lines.append("")
    lines.append("| Component | Version | Health / Status |")
    lines.append("|-----------|---------|-----------------|")

    cluster = state.get("cluster", {})
    if "consul" in cluster:
        c = cluster["consul"]
        members = ", ".join(c.get("members", []))
        lines.append(f"| Consul | {c['version']} | {len(c.get('members', []))} members: {members} |")
    if "nomad" in cluster:
        n = cluster["nomad"]
        members = ", ".join(n.get("members", []))
        lines.append(f"| Nomad | {n['version']} | {len(n.get('members', []))} members: {members} |")
    if "ceph" in cluster:
        ce = cluster["ceph"]
        lines.append(
            f"| Ceph | {ce['version']} ({ce.get('codename', '')}) | {ce['health']}, {ce.get('osds', '?')} OSDs |"
        )
    lines.append("")

    # Host details
    lines.append("## Hosts")
    lines.append("")

    hosts = state.get("hosts", {})
    if hosts:
        # Package versions table
        lines.append("### Installed Packages")
        lines.append("")

        # Collect all package names across hosts
        all_pkgs = set()
        for info in hosts.values():
            all_pkgs.update(info.get("packages", {}).keys())
        pkg_list = sorted(all_pkgs)

        header = "| Package | " + " | ".join(sorted(hosts.keys())) + " |"
        sep = "|---------|" + "|".join(["---------"] * len(hosts)) + "|"
        lines.append(header)
        lines.append(sep)
        for pkg in pkg_list:
            row = f"| {pkg} |"
            for host in sorted(hosts.keys()):
                ver = hosts[host].get("packages", {}).get(pkg, "—")
                row += f" {ver} |"
            lines.append(row)
        lines.append("")

        # Service states table
        lines.append("### Service States")
        lines.append("")
        all_svcs = set()
        for info in hosts.values():
            all_svcs.update(info.get("services", {}).keys())
        svc_list = sorted(all_svcs)

        header = "| Service | " + " | ".join(sorted(hosts.keys())) + " |"
        sep = "|---------|" + "|".join(["---------"] * len(hosts)) + "|"
        lines.append(header)
        lines.append(sep)
        for svc in svc_list:
            row = f"| {svc} |"
            for host in sorted(hosts.keys()):
                st = hosts[host].get("services", {}).get(svc, "—")
                row += f" {st} |"
            lines.append(row)
        lines.append("")

        # Host summary table
        lines.append("### System Info")
        lines.append("")
        lines.append("| Host | OS | Kernel | RAM (MB) | vCPUs | IP |")
        lines.append("|------|----|--------|----------|-------|----|")
        for host in sorted(hosts.keys()):
            info = hosts[host]
            lines.append(
                f"| {host} | {info.get('os', '—')} | {info.get('kernel', '—')} "
                f"| {info.get('ram_mb', '—')} | {info.get('vcpus', '—')} | {info.get('ip', '—')} |"
            )
        lines.append("")

    # Deployed jobs
    lines.append("## Deployed Jobs")
    lines.append("")

    jobs = state.get("jobs", {})
    intended = state.get("intended_images", {})

    if jobs or intended:
        lines.append("| Job | Status | Type | Node | Live Image | Intended Image | Drift |")
        lines.append("|-----|--------|------|------|------------|----------------|-------|")

        # Merge job names from both sources
        all_jobs = sorted(set(list(jobs.keys()) + list(intended.keys())))
        for job_name in all_jobs:
            job = jobs.get(job_name, {})
            status = job.get("status", "not running")
            job_type = job.get("type", "—")
            node = job.get("node", "—")
            live_img = job.get("image_live", "—")
            intended_img = intended.get(job_name, "—")

            # Drift detection
            if live_img != "—" and intended_img != "—" and live_img != "unknown":
                drift = "DRIFT" if live_img != intended_img else "ok"
            else:
                drift = "—"

            lines.append(
                f"| {job_name} | {status} | {job_type} | {node} | {live_img} | {intended_img} | {drift} |"
            )
        lines.append("")

    lines.append(f"---\n*Generated by `make capture-state`*\n")

    output_path.write_text("\n".join(lines))
    print(f"Wrote {output_path}")


if __name__ == "__main__":
    main()
```
